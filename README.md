# ☕ Coffee Shop Sales Dashboard

## 📌 Project Overview
This project analyzes coffee shop sales data using Microsoft Excel. The dashboard provides interactive insights into sales performance across stores, products, categories, months, days, and hours.

## 🎯 Objectives
- Analyze overall sales performance.
- Identify top-performing stores and products.
- Discover sales trends over time.
- Support business decisions using data.

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- KPIs
- Dashboard Design

## 📊 KPIs
- Total Revenue: $698,812.33
- Total Transactions: 149,116
- Total Quantity Sold: 214,470
- Average Transaction Value: $4.69

## 💡 Key Insights
- Hell's Kitchen generated the highest revenue.
- Coffee was the highest revenue-generating category.
- Barista Espresso generated the highest revenue among products.
- Revenue increased steadily from March to June.
- Sales peaked during the morning hours.
- Monday recorded the highest revenue.
